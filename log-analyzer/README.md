# Security Log Analyzer

Pythonで作成した、学習用のセキュリティログ解析ツールです。

ログファイルを読み込み、ログレベルの集計やログイン失敗の分析を行います。

短時間に集中したログイン失敗を検出し、追加調査が必要なイベントの候補として表示します。

解析結果はCSVファイルとグラフとして保存します。

---

## 主な機能

- INFO / WARNING / ERROR の件数を集計
- ログイン失敗を検出
- ユーザー別にログイン失敗回数を集計
- `datetime` を利用したログ時刻の解析
- 短時間に集中したログイン失敗を検出
- 検出結果をCSVへ保存
- ログレベル集計結果をCSVへ保存
- Matplotlibによるグラフ作成
- コマンドラインから解析対象ログを指定

---

## 検出ルール

現在の学習用設定では、

- 60秒以内
- 同じユーザーで3回以上ログイン失敗

という条件を満たした場合に、調査候補として表示します。

例：

```text
⚠ test : 30秒以内に3回ログイン失敗
```

この結果だけで攻撃と断定することはできません。

正常なユーザーによるパスワードの入力ミスなどでも条件に一致する可能性があるため、追加調査が必要なイベントを抽出する目的で使用します。

## インストール

必要なライブラリをインストールします。

```bash
python -m pip install -r requirements.txt
```

---

## 実行方法

`log-analyzer` フォルダへ移動して、次のコマンドを実行します。

```bash
python log_analyzer.py sample.log
```

別のログファイルを解析する場合：

```bash
python log_analyzer.py server.log
```

## セキュリティ上の考え方

ログイン失敗が多いという理由だけで、攻撃と判断することはできません。

このツールでは、

```text
ログ
  ↓
WARNING
  ↓
Login failed
  ↓
ユーザー別に集計
  ↓
発生時刻を解析
  ↓
短時間に集中しているか確認
  ↓
調査候補として検出
```

という流れで分析しています。

検出結果は攻撃の確定ではなく、追加調査のための情報として扱います。

---

## 注意事項

このプロジェクトは、Pythonおよびセキュリティログ解析の学習を目的として作成しています。

実際のシステムで使用する場合は、対象システムのログ形式に合わせた解析処理や検出ルールの調整が必要です。

実際のログをGitHubなどへ公開する場合は、ユーザー名、IPアドレス、メールアドレス、ホスト名、APIキー、トークンなどの機密情報が含まれていないことを確認してください。
